# Contributing to 3D Gaussian Splatting App

Thank you for your interest in contributing! We welcome improvements, bug fixes, and new features.

## Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/3d-gaussian-splatting-app.git
   cd 3d-gaussian-splatting-app
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Setup

### Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Frontend
```bash
cd frontend
npm install
```

## Guidelines

- **Code style**: Follow PEP 8 for Python, Prettier for JavaScript
- **Tests**: Add tests for new features
- **Commits**: Use clear, descriptive commit messages
- **Pull requests**: Reference related issues

## Before Submitting

1. Test your changes locally
2. Run linters and tests
3. Update documentation if needed
4. Ensure no secrets or sensitive data are included

## Questions?

Open an issue to discuss larger changes before implementing them.

Thank you for contributing! 🎉
